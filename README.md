# Capitulín - Juegos Matemáticos 🎮👑

## ✅ FUNCIONA EN LOCAL Y EN GITHUB PAGES

### 📦 Archivos incluidos:

**Juegos principales:**
- `inicio.html` - Página de inicio (EMPIEZA AQUÍ)
- `multiplicaciones.html` - Juego de multiplicaciones
- `index.html` - Juego de sumas/restas  

**Archivos PWA (solo para GitHub/servidor):**
- `manifest.json` + `sw.js` - PWA de multiplicaciones
- `manifest-sumas.json` + `sw-sumas.js` - PWA de sumas

### 🚀 CÓMO USAR:

#### ✅ EN LOCAL (tu computadora):
1. **Haz doble clic en `inicio.html`**
2. Elige el juego que quieras
3. ¡Ya funciona! 🎮

**Nota:** En local funciona el juego pero NO se puede instalar como app.

---

#### ✅ EN GITHUB PAGES (recomendado):

**Subir a GitHub:**
1. Crea un repositorio en GitHub
2. Sube TODOS los archivos
3. Ve a Settings → Pages → Deploy from main branch
4. Espera 1-2 minutos
5. Abre la URL: `https://tuusuario.github.io/turepositorio/inicio.html`

**Beneficios en GitHub Pages:**
- ✅ Funciona perfecto
- ✅ Se puede instalar como app (botón "📱 Instalar App")
- ✅ Funciona sin internet después de instalar
- ✅ Puedes compartir el enlace con estudiantes

---

### 🎯 MULTIPLICACIONES:

#### Sistema de Juego:
- **Tablas del 2 al 10** + Modo Mixto
- **3 Dificultades:**
  - 😊 Fácil: Tablas 2-5, multiplicadores 1-10 (no se repiten)
  - 😐 Medio: Tablas 2-10, multiplicadores 1-10
  - 😤 Difícil: Tablas 2-12, multiplicadores 1-12

### ➕➖ SUMAS Y RESTAS:

#### Sistema de Juego:
- **Sumas, Restas o Mixto**
- **3 Dificultades:**
  - 😊 Fácil: 0-10 (no se repiten números)
  - 😐 Medio: 1-20
  - 😤 Difícil: 1-50
