# Capitulín - Multiplicaciones Mágicas 🎮👑

## PWA Instalable - Optimizado para Pizarras PDI

### 📦 Archivos incluidos:
- `multiplicaciones.html` - Juego principal
- `manifest.json` - Configuración de la PWA
- `sw.js` - Service Worker para funcionalidad offline

### 🚀 Instalación:

#### Opción 1: En Servidor Web (Recomendado para PDI)
1. Sube los 3 archivos a tu servidor web
2. Accede desde Chrome/Edge en la PDI
3. Haz clic en el botón "📱 Instalar App" 
4. ¡Listo! Ahora funciona offline

#### Opción 2: Instalación Local
1. Abre `multiplicaciones.html` en un navegador moderno
2. Si ves el botón "📱 Instalar App", haz clic
3. La app se instalará en tu dispositivo

### ✨ Características:

#### 🎯 Sistema de Juego:
- **Tablas del 2 al 10** + Modo Mixto
- **3 Dificultades:**
  - 😊 Fácil: Tablas 2-5, multiplicadores 1-10, no se repiten
  - 😐 Medio: Tablas 2-10, multiplicadores 1-10
  - 😤 Difícil: Tablas 2-12, multiplicadores 1-12

#### 🛒 Tienda de Power-Ups (10 coronas):
- ❤️ **Vida Extra** - Se activa inmediatamente
- ⛑️ **Casco Protector** - Botón de activación (3 golpes)
- ☂️ **Paraguas Mágico** - Botón de activación (25s)
- 📢 **Silbato Antimonstruos** - Botón de activación (elimina todo)

#### 👾 Enemigos:
- **Monstruos cayendo del cielo** (desaparecen al tocar suelo)
- Máximo 2 en fácil, 3 en medio, 4 en difícil
- **Bruja voladora** (70x70px) aparece a mitad del nivel
- La bruja te quita 5 coronas si te toca

#### 🎮 Controles PDI:
- **Optimizado para pantallas grandes en horizontal**
- **Botones táctiles** grandes para fácil interacción
- **Teclado:** Flechas + Espacio/Enter
- Plataformas accesibles en todos los niveles
